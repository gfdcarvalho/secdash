# SecDash
##  Dashboard de Vulnerabilidades de Segurança Multi-Repositório
O projeto SecDash é uma plataforma web que agrega e visualiza vulnerabilidades de segurança identificadas por ferramentas externas (como GitHub Dependabot e GitLab SAST) em múltiplos repositórios. O objetivo é fornecer um dashboard unificado e interativo que permita a arquitetos e líderes de desenvolvimento monitorar o risco de segurança de todos os seus projetos num único lugar.
